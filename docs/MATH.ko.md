# 수학 원리와 실패 방식

## 1. Rank-one 편집(ROME)

가중치 `W ∈ R^{d_out × d_in}`가 `W′ k = v`를 만족하면서 가능한 적게 변하기를 원합니다. 이 단일 선형 제약의 최소 Frobenius 노름 해는 rank one입니다:

```
ΔW = (v − W k) kᵀ / (kᵀ k)
```

확인: `ΔW k = (v − Wk)(kᵀk)/(kᵀk) = v − Wk`, 따라서 `W′ k = v`. ∎

key에는 정확하지만 다른 입력에 대해 **아무것도** 말하지 않습니다. 이것이 순진한 ROME 편집이 이웃을 망가뜨리는 이유입니다.

## 2. 영공간 제약 편집

`K = [k₁ … kₙ]ᵀ`를 바꾸고 싶지 않은 key, `Q`를 `span(K)`의 정규직교 기저(`K`의 SVD)라고 합시다. 정의:

```
P  = I − Q Qᵀ
k⊥ = P k
```

`k⊥`는 모든 보호 key와 직교합니다. 이것을 쓰기 방향으로 씁니다:

```
ΔW = (v − W k) k⊥ᵀ / (k⊥ᵀ k)
```

두 성질:

* **타깃** —— `ΔW k = (v − Wk)(k⊥ᵀk)/(k⊥ᵀk) = v − Wk`, 즉 `W′ k = v`. 정확.
* **보호** —— 각 `i`에 대해 `ΔW kᵢ = (v − Wk)(k⊥ᵀ kᵢ)/(k⊥ᵀk) = 0`. 정확.

분자는 **원래** `k`를 쓰고 `k⊥`가 아닙니다. 양쪽에 `k⊥`를 쓰는 것은 흔한 버그로, 값은 들어가지만 불필요한 노름을 씁니다.

구현 세부: `d_in × d_in` 투영 행렬을 실체화하지 않습니다. 기저 형식은 적용 비용이 `O(d_in · r)`이고, `d_in = 4096`에서 밀집 행렬은 레이어당 128 MB입니다.

## 3. 방향 절제

모듈 출력의 단위 방향 `d` 성분을 제거하려면:

```
W′ = (I − d dᵀ) W
```

residual stream에 쓰는 모든 행렬에 적용하면 데이터 없이 행동(거부 방향, 스타일 방향)을 제거합니다. 한 줄, 제로 그래디언트. 그래서 위험하기도 합니다 — 아래 안전 메모를 보세요.

## 4. 방향 주입

추론 시 steering은 hidden state에 `α d`를 더합니다. residual stream은 가산적이므로, 거기에 쓰는 모듈에 rank-one 항을 더하는 것과 같습니다:

```
ΔW = α d aᵀ / (aᵀ a)
```

`a`는 대표 입력 활성화. 그러면 `W′ a = W a + α d` — steering 벡터가 가중치에 구워져 런타임 hook이 필요 없습니다.

## 5. 예산

```
rel(ΔW) = ‖ΔW‖_F / ‖W‖_F
```

레이어를 넘어 일반화되는 유일한 안전 다이얼입니다. `max_rel_norm`으로 클립하면 delta를 줄이고 **정확한 target 보장을 깨뜨립니다** — 의도적으로. 클립된 편집은 허용한 것보다 모델을 더 쓰지 않고 덜 전달합니다.

경험적 출발점:

| 편집 유형 | 예산 |
|---|---|
| 사실형, `down_proj` | 0.01 – 0.03 |
| 행동형, `o_proj` | 0.05 – 0.15 |
| ablation | 클립하지 않음. KL 측정 |

## 실패 방식

| 증상 | 원인 | 해결 |
|---|---|---|
| 정확한 prompt는 되지만 바꿔쓰기 실패 | key가 하나의 token 열에 묶임 | 5–20개 바꿔쓰기 평균 |
| 단답은 맞지만 장문이 무너짐 | 편집이 하류 계산을 깨뜨림 | 얕은 레이어, 낮은 예산, 강한 투영 |
| 능력 하락 | 레이어가 너무 중앙 | 2–4 레이어 얕게 |
| 무관한 prompt 드리프트 | 영공간 제약 없음 | 보호 key 집합 추가 |
| bf16에서 아무 변화 없음 | delta가 반올림으로 사라짐 | float64로 계산 후 되돌림 |
| 누적 편집으로 모델 붕괴 | delta 누적 | `Σ‖ΔWᵢ‖/‖W‖`를 ~0.1로 제한 후 재계산 |

## 보장이 끝나는 곳

위의 모든 것은 **1차이고 국소적**입니다. `ΔW kᵢ = 0`은 보호 집합의 정확한 벡터에 성립하고, 주변 입력은 근사적으로만 보존됩니다. 하류 비선형성이 작은 오차를 증폭합니다. 더 복잡한 함수 변화는 저랭크, 방향, 다중 편집 조합이 담당합니다.

이 공식들은 칼날 폭이 알려진 메스로 다루고, "다른 것은 아무것도 움직이지 않았다"는 증명으로 쓰지 마세요. 그래서 게이트가 있습니다.

## 안전

방향 절제는 한 줄로 안전 정렬을 제거할 수 있습니다. 이 라이브러리의 배포에서는 모든 편집의 추가 전용 감사 로그를 유지하고, 거부 행동을 제거하려는 의도의 편집을 거부하고, 체크포인트를 인플레이스로 덮어쓰지 마세요.
