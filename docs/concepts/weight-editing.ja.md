# 重み編集

**編集**とは、1 つ以上の重み行列への加法的変更です：

```
W' = W + ΔW
```

Machaon は `ΔW` を**導出可能**な族に制限し、編集の効果を願望ではなく推論できるようにします。

## 行動空間

| レベル | agent が選ぶもの | 数学が行うこと | 状態 |
|---|---|---|---|
| L0 | どの procedure、どの層 | まだ何もしない | ✅ `procedures.rome` |
| L1 | tensor 上の Python 関数 | 実行する | 次 |
| L2 | target key/value の組 | rank-one 求解 | ✅ `rank1_constrained` |
| L3 | 解釈可能な方向 | ablation / injection | ✅ `ablate_*`、`bake_direction` |
| L4 | 疎なスカラー集合 | 直接代入 | `Workspace` 経由 |
| L5 | 構造：剪枝、マージ、配線変更 | merge/prune ツールが担当。delta はここで監査可能 | 相互運用 |

公開研究の多くは L2 と L3 にあります。L0 がアルゴリズムをツールにします：モデルが**どこ**と**どれだけ**を決め、数学が**何を**変えるかを決めます。

## 良い編集の 3 性質

### 1. 局所性

1 つの prompt の答えを変えても、無関係な prompt の答えは変わってはいけません。最も早く、最も大きく壊れる性質です。Machaon は保護 key 集合上の零空間投影で対処します。[零空間投影](null-space.md)を参照。

保護 key では `‖ΔW kᵢ‖ / ‖W kᵢ‖`、無関係な prompt では KL ダイバージェンスで測ります。

### 2. 有効性

編集は実際にそのことを行わなければなりません。元の prompt **と、base model がもともと同じように答えていた言い換え**で測ります。base model が答えられない言い換え集合は汎化テストではなくノイズです。

### 3. 可逆性

正確に元へ戻せなければなりません。Machaon は適用前に元のバイトをコピーし、`rollback()` がビット単位で復元します。

## 編集とは何か

- 重みの変更。モデルパラメータ上の optimizer はありません：求解は閉形式か、単一 value ベクトル上の勾配です。
- 永続的。コンテキスト、system prompt、再起動を越えて残ります。
- コストがある。各編集は予算 `‖ΔW‖_F / ‖W‖_F` を使います。

## 予算

```
rel(ΔW) = ‖ΔW‖_F / ‖W‖_F
```

経験的な出発点：

| 編集 | 予算 |
|---|---|
| 事実型、`down_proj` / `c_proj` | 0.01 – 0.03 |
| 行動型、`o_proj` | 0.05 – 0.15 |
| ablation | クリップしない。KL を測る |

クリップは意図的です：厳密な target 保証を壊す代わりに、編集が許可量を超えないようにします。
