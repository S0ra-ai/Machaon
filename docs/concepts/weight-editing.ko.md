# 가중치 편집

**편집**은 하나 이상의 가중치 행렬에 대한 가산적 변경입니다:

```
W' = W + ΔW
```

Machaon은 `ΔW`를 **유도 가능한** 패밀리로 제한해, 편집의 효과를 바람이 아니라 추론으로 다룰 수 있게 합니다.

## 행동 공간

| 레벨 | agent가 선택하는 것 | 수학이 하는 일 | 상태 |
|---|---|---|---|
| L0 | 어떤 procedure, 어느 레이어 | 아직 아무것도 안 함 | ✅ `procedures.rome` |
| L1 | tensor 위의 Python 함수 | 실행 | 다음 |
| L2 | target key/value 쌍 | rank-one 풀이 | ✅ `rank1_constrained` |
| L3 | 해석 가능한 방향 | ablation / injection | ✅ `ablate_*`, `bake_direction` |
| L4 | 희소 스칼라 집합 | 직접 대입 | `Workspace` 경유 |
| L5 | 구조: 프루닝, 병합, 재배선 | merge/prune 도구가 담당; delta는 여기서 감사 가능 | 상호운용 |

공개 연구의 대부분은 L2와 L3에 있습니다. L0가 알고리즘을 도구로 만듭니다: 모델이 **어디**와 **얼마나**를 정하고, 수학이 **무엇을** 바꿀지 정합니다.

## 좋은 편집의 세 가지 성질

### 1. 국소성

한 prompt의 답을 바꾸면서 무관한 prompt의 답은 바뀌지 않아야 합니다. 가장 먼저, 가장 크게 깨지는 성질입니다. Machaon은 보호 key 집합 위의 영공간 투영으로 대응합니다. [영공간 투영](null-space.md)을 참고하세요.

보호 key에서는 `‖ΔW kᵢ‖ / ‖W kᵢ‖`, 무관한 prompt에서는 KL divergence로 측정합니다.

### 2. 유효성

편집은 실제로 그 일을 해야 합니다. 원래 prompt **와 base model이 원래 같게 답하던 바꿔쓰기**에서 측정합니다. base model이 틀리는 바꿔쓰기 집합은 일반화 테스트가 아니라 노이즈입니다.

### 3. 가역성

정확히 되돌릴 수 있어야 합니다. Machaon은 적용 전 원본 바이트를 복사하고 `rollback()`이 비트 단위로 복원합니다.

## 편집이란 무엇인가

- 가중치 변경. 모델 파라미터 위의 optimizer는 없습니다: 풀이는 폐형식이거나 단일 value 벡터 위의 그래디언트입니다.
- 영속적. 컨텍스트, system prompt, 재시작을 넘어 남습니다.
- 비용이 있음. 모든 편집은 예산 `‖ΔW‖_F / ‖W‖_F`를 씁니다.

## 예산

```
rel(ΔW) = ‖ΔW‖_F / ‖W‖_F
```

경험적 출발점:

| 편집 | 예산 |
|---|---|
| 사실형, `down_proj` / `c_proj` | 0.01 – 0.03 |
| 행동형, `o_proj` | 0.05 – 0.15 |
| ablation | 클립하지 않음; KL을 측정 |

클립은 의도적입니다: 정확한 target 보장을 깨는 대신, 편집이 허용한 양을 넘지 않게 합니다.
