## 隣接ツール

Machaon の単位は既存モデルへの標的編集です。近くの仕事には成熟したツールがあり、その成果物はこの契約と組み合わせられます：

- **マージと task arithmetic：** mergekit delta は `machaon.tools` と `machaon.verify` で監査・適用できます。
- **剪枝と再配線：** 構造編集は delta として届き、同じ予算とゲートを通ります。
- **ファインチューニングと LoRA：** 等予算 LoRA baseline は [`RESULTS.md`](RESULTS.md#r9-equal-budget-lora-baseline) で実測済み。adapter delta は rank-one 編集と比較できます。
- **推論サービス：** `Checkpoint.write_with` で編集済みチェックポイントを書き出し、任意の Hugging Face 互換スタックで提供できます。
