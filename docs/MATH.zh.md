# 数学原理与失效方式

## 1. Rank-one 编辑（ROME）

我们希望权重 `W ∈ R^{d_out × d_in}` 满足 `W′ k = v`，同时尽量少改。这个单线性约束的最小 Frobenius 范数解是 rank one：

```
ΔW = (v − W k) kᵀ / (kᵀ k)
```

验证：`ΔW k = (v − Wk)(kᵀk)/(kᵀk) = v − Wk`，因此 `W′ k = v`。∎

它对 key 精确，对其他输入不加约束。这就是朴素 ROME 编辑可能移动邻居的原因。

## 2. 零空间约束编辑

令 `K = [k₁ … kₙ]ᵀ` 是你拒绝改变的 key，`Q` 是 `span(K)` 的正交基（来自 `K` 的 SVD）。定义

```
P  = I − Q Qᵀ
k⊥ = P k
```

`k⊥` 与每个受保护 key 正交。用它作为写入方向：

```
ΔW = (v − W k) k⊥ᵀ / (k⊥ᵀ k)
```

两个性质：

* **目标** —— `ΔW k = (v − Wk)(k⊥ᵀk)/(k⊥ᵀk) = v − Wk`，因此 `W′ k = v`。精确。
* **保护** —— 对每个 `i`，`ΔW kᵢ = (v − Wk)(k⊥ᵀ kᵢ)/(k⊥ᵀk) = 0`。精确。

注意分子使用**原始** `k`，不是 `k⊥`。两边都用 `k⊥` 是常见 bug：它能把值打进去，但会多花不必要的范数。

实现细节：我们从不显式构造 `d_in × d_in` 投影矩阵。基形式应用成本是 `O(d_in · r)`；当 `d_in = 4096` 时，稠密投影每层要 128 MB。

## 3. 方向消融

要移除模块输出沿单位方向 `d` 的分量：

```
W′ = (I − d dᵀ) W
```

作用到每个写入 residual stream 的矩阵，就能不借助任何数据移除一种行为（拒绝方向、风格方向）。一行，零梯度。这也是这项能力属于双用途的原因——见下面的安全控制。

## 4. 方向注入

推理时 steering 会给 hidden state 加 `α d`。由于 residual stream 是加性的，这等价于给写入该处的模块加一个 rank-one 项：

```
ΔW = α d aᵀ / (aᵀ a)
```

其中 `a` 是代表性输入激活。于是 `W′ a = W a + α d`——steering 向量被烘进权重，不再需要运行时 hook。

## 5. 预算

```
rel(ΔW) = ‖ΔW‖_F / ‖W‖_F
```

这是唯一能跨层通用的安全旋钮。裁剪到 `max_rel_norm` 会缩小 delta，**打破精确 target 保证**——这是刻意的。被裁剪的编辑会少交付，而不是比你授权的更多地消耗模型。

经验起点：

| 编辑类型 | 预算 |
|---|---|
| 事实型，`down_proj` | 0.01 – 0.03 |
| 行为型，`o_proj` | 0.05 – 0.15 |
| ablation | 不裁剪；改测 KL |

## 6. 预算感知覆盖

当完整受保护集合放不进预算时，Machaon 可以认证一个子集，而不是裁剪整个更新。`machaon.contract.synthesize_contract` 从无保护 rank-one 编辑出发，在精确更新仍满足 `max_rel_norm` 时贪心加入候选 key。返回的更新精确满足目标，并对每个已接纳 key 精确不变；被拒绝的 key 会明确返回。这样以部分覆盖为代价保住了目标，而不是像裁剪那样牺牲目标。

## 诊断与恢复

| 症状 | 原因 | 修复 |
|---|---|---|
| 精确 prompt 有效，改写失败 | key 绑定单一 token 序列 | 对 5–20 个改写取平均 |
| 短答正确，长文本不连贯 | 编辑破坏了下游计算 | 更浅的层、更低预算、更强投影 |
| 能力下降 | 层太居中 | 往浅层移动 2–4 层 |
| 无关 prompt 漂移 | 没有零空间约束 | 加受保护 key 集 |
| bf16 下什么都没变 | delta 被舍入吃掉 | 用 float64 计算，之后再合并 |
| 累计编辑让模型漂移 | delta 累积 | 把 `Σ‖ΔWᵢ‖/‖W‖` 限制在 ~0.1，然后重新计算 |

## 适用范围

该构造为受保护集合中的向量提供精确证书，并在被编辑的 key 上精确实现目标。更广泛的局部性由留出探针、中性 prompt、困惑度和任务准确率来测量。这一分工很有用：它把“契约证明了什么”和“评估量化了什么”分开。低秩、方向和多编辑组合可以用同一模式扩展到更大的函数变化。

预算、受保护集合的秩和验收门共同界定了适用范围，部署方可以据此选择与风险承受度匹配的工作点。

## 安全控制

方向消融可以一行移除安全对齐。Machaon 因此提供声明式意图、接受前拒绝规则、追加式审计记录、累计预算和 fail-closed 验收门。部署时应保留审计日志，审查针对拒绝行为的编辑，并写入新的检查点而不是覆盖源检查点。
