# 웹 콘솔

로컬 웹 콘솔은 Python API, CLI, MCP 서버와 동일한
`machaon.tools` / `machaon.session` 위에 놓인 얇은 진입점입니다. 모델 로직을
복제하지 않고, 세 진입점이 같은 트랜잭션 계약을 공유합니다.

```text
브라우저 ──> FastAPI / SSE ──> machaon.tools / machaon.session
                                  │
                    CLI ──────────┤
                    MCP server ───┘
```

## 설치와 실행

핵심 패키지는 NumPy만 필요합니다. 웹 콘솔을 사용할 때 선택 의존성을 추가합니다.

```bash
pip install "machaon[web]"
machaon web --allowed-root /models --port 8765
# machaon-web도 같은 실행기입니다
```

실행하면 일회용 token이 포함된 로컬 URL을 출력합니다. 서버는 기본적으로
`127.0.0.1`에만 바인딩됩니다. `--allowed-root` 또는
`MACHAON_WEB_ALLOWED_ROOTS`로 checkpoint 루트를 지정하세요.
`torch`, `transformers`, `safetensors`가 없으면 첫 session이 조용히 실패하는 대신
정확한 `pip install "machaon[hf]"` 명령을 banner로 보여 줍니다.

## 인터페이스

콘솔은 한 페이지입니다. 상단 체크포인트 바, **사실 가르치기** 입력 영역, 그리고
**모델**, **편집**, **가중치 프로그램**, **결과** 네 개의 네이티브 접기 영역이
있습니다. 첫 방문 모달이나 별도 hero는 없으며, 조작 순서가 곧 페이지 순서입니다.

### 체크포인트 바

체크포인트 디렉터리 또는 단일 `.safetensors` 파일을 붙여 넣고 **검사**를 누릅니다.
**찾아보기**는 허용 루트 아래의 체크포인트를 나열합니다. 정상적으로 열거나 저장한
경로는 `localStorage`에 기록되어 새로고침 후에도 복원됩니다.

### 사실 가르치기

이것이 주 경로입니다. 한 문장을 입력합니다.

```text
The Eiffel Tower is in the city of -> Rome
```

체크포인트가 없으면 스타터를 선택하고, 필요하면 CPU, 자동, Apple MPS, CUDA를 고른 뒤
**가르치기**를 누릅니다. `machaon intent`와 같은 문법으로 문장을 해석하고, 선택한
체크포인트를 열거나 필요할 때 스타터를 내려받고, 티칭 레시피를 실행한 뒤 CLI와 같은
목표·예산·panel·KL 증거를 보여 줍니다. 거부된 편집은 롤백됩니다.

적용 후에는 출력 경로와 **저장**이 나타납니다. 저장은 새 체크포인트를 쓰고,
**저장본 열기**는 편집 세션을 닫은 뒤 저장된 바이트를 열어 답을 다시 검증하고 입력을
비웁니다. 이미 세션이 열려 있으면 같은 카드에서 그 모델을 바로 가르칠 수 있습니다.
실행에 더 이상 영향을 주지 않는 스타터와 장치 선택기는 숨겨집니다.

**여러 사실**은 누적 다중 사실 체인을 시작합니다. **프로그램 만들기**는 현재 사실을
편집 가능한 `.machaon` 프로그램으로 만듭니다. 둘 다 성공한 편집 뒤에도 사용할 수
있습니다.

### 모델

**모델**에는 header 검사, tensor 이름·모양·타입, 선택적 스타터 다운로드, 세션
dtype·장치·예산 설정, 기준선 캡처, 가중치를 바꾸지 않는 단일 사실 검증이 있습니다. 다운로드는
SSE로 endpoint, 파일, 바이트 진행률을 보여 주며 **다운로드 후 열기**는 완료 시
세션을 엽니다.

**사실 검증**은 선택한 체크포인트를 다시 불러와 하나의 prompt/answer 또는 한 줄에
하나씩 사실을 평가하고 PASS/FAIL, 답, 정확도를 표시합니다. `/api/check`를 호출하며
세션을 편집하지 않습니다.

### 편집

**편집**은 정확한 계약 편집기입니다. prompt, target, 보호 프롬프트, 제안,
적용, 평가, 롤백을 다룹니다. 제안은 dry run이고 **적용**은 트랜잭션 안에서 쓰며
누적 예산을 소비합니다. 게이트 실패나 롤백은 원본 바이트를 복원합니다.

**고급 편집**에서 layer, solver, steps, 학습률, module suffix, 상대 예산, densify를
설정합니다. **여러 사실**은 사실마다 전체 검색을 실행하고 누적 예산과 원본 panel
드리프트를 확인합니다. **일괄 편집**은 여러 prompt와 활성화 행을 받아
exact/clamped, 오차, rank, key별 오차를 보고합니다.

### 가중치 프로그램

**가중치 프로그램**은 `machaon program`과 같은 `.machaon` 텍스트 또는 JSON을
받습니다. **확인**은 `/api/program/plan`을 호출해 모델을 읽지 않고 경로, 사실, 예산,
장치, 출력을 해석합니다. **실행**은 백그라운드 작업으로 체인을 실행하고
`<output>/program-report.json`을 쓴 뒤, 저장된 체크포인트를 다시 불러와 모든 사실을
검증한 다음 수락합니다.

**더 보기**에는 프로그램 폴더와 리포트 경로, 현재 체크포인트 프리필, 로컬
`.machaon` 가져오기, SmolLM2 / 두 사실 / 이중 언어 Qwen 템플릿, 최근 프로그램과
실행, 사실 목록 생성기, 리포트 검증이 있습니다. **리포트 검증**은 SHA-256과 구조를
확인하고, **리포트 + 모델 검증**은 체크포인트도 다시 불러와 사실을 재실행합니다.
선택 체크박스로 현재 프로그램과 일치하거나 기록된 경로 대신 선택한 체크포인트를
사용하도록 요구할 수 있습니다. 상대 경로와 모든 브라우저 파일 접근은 같은 허용
목록을 따릅니다.

### 결과

**결과**에는 최신 제안, fail-closed 게이트 판정, 체크포인트 저장, WSP 컨트롤,
트랜잭션 활동 로그가 있습니다. WSP는 리포트 감사, 세션 평가, 증거 저장, OpenWSP
내보내기, 바인딩 검증을 지원합니다. 게이트 지표 누락은 계속 실패입니다.

### 로컬 상태와 언어

콘솔은 English, 简体中文, 日本語, 한국어를 제공합니다. 상단 선택기는 정적 문구와
동적 작업/증거 메시지를 함께 바꾸고, 선택을 `localStorage`에 저장하며
`?lang=zh`, `?lang=ja`, `?lang=ko` 직접 링크를 지원합니다. 최근 프로그램과 실행은
로컬 기록일 뿐이며 업로드되지 않습니다.

## 대형 체크포인트 예시: Qwen3.6-27B

콘솔은 모델에 독립적이며 같은 컨트롤이 모든 지원 아키텍처에 적용됩니다.
27B는 대형 체크포인트의 한 예시입니다. 34 GB 통합 메모리 환경에서는 `int4`
또는 `int8`을 사용하고 언어 디코더의 뒤쪽 layer를 편집 지점으로 삼습니다.

```text
path:      ./qwen36-27b
dtype:     auto
quantize:  int4
device:    cpu
layer:     60
budget β:  0.01
module:    mlp.down_proj
solver:    gradient
densify:   on
```

먼저 header만으로 checkpoint를 확인하세요. Transformers runtime, 단일 shard
쓰기, `Checkpoint.write_tensor`의 자세한 내용은
[Qwen3.6-27B 가이드](../guides/qwen27b.md)에 있습니다.

## 운영 규칙

콘솔은 loopback에 두고, 허용 루트를 실제로 편집하는 checkpoint 디렉터리로
좁히세요. 출력된 token은 session과 checkpoint 쓰기를 승인하는 임시 capability
입니다. 웹 계층은 임의 Python 코드를 받지 않으며 경로 허용 목록, 예산 검사,
트랜잭션 rollback을 통과합니다.
