# Web コンソール

ローカル Web コンソールは、Python API、CLI、MCP サーバーと同じ
`machaon.tools` / `machaon.session` をブラウザから使うための薄い入口です。
モデル処理を複製せず、三つの入口が同じトランザクション契約を共有します。

```text
ブラウザ ──> FastAPI / SSE ──> machaon.tools / machaon.session
                                  │
                    CLI ──────────┤
                    MCP server ───┘
```

## インストールと起動

コアは NumPy だけで動作します。Web コンソールには追加依存を入れます。

```bash
pip install "machaon[web]"
machaon web --allowed-root /models --port 8765
# machaon-web も同じランチャーです
```

起動時に一度だけ使う token を含む URL が表示されます。サーバーは既定で
`127.0.0.1` にだけバインドされます。`--allowed-root` または
`MACHAON_WEB_ALLOWED_ROOTS` で checkpoint のルートを指定してください。
`torch`、`transformers`、`safetensors` のいずれかがない場合、最初の session が
黙って失敗する代わりに、正確な `pip install "machaon[hf]"` コマンドを banner で
表示します。

## インターフェース

コンソールは 1 ページです。上部のチェックポイントバー、**事実を教える** 入力欄、
そして **モデル**、**編集**、**重みプログラム**、**結果** の 4 つのネイティブな
折りたたみがあります。初回モーダルや独立した hero はなく、操作順がそのまま
ページ順です。

### チェックポイントバー

チェックポイントのディレクトリまたは単一の `.safetensors` ファイルを貼り、
**確認** を押します。**参照** は許可ルート内のチェックポイントを一覧します。
正常に開くか保存した後、パスは `localStorage` に保存され、更新後も復元されます。

### 事実を教える

これが主経路です。1 文を入力します。

```text
The Eiffel Tower is in the city of -> Rome
```

チェックポイントがない場合はスターターを選び、必要なら CPU、自動、Apple MPS、
CUDA を選んで **教える** を押します。`machaon intent` と同じ文法で解析し、選択した
チェックポイントを開くか必要なスターターをダウンロードし、教学レシピを実行して、
CLI と同じ目標・予算・panel・KL の証拠を表示します。拒否された編集は
ロールバックされます。

適用後は出力パスと **保存** が表示されます。保存すると新しいチェックポイントを
書き出し、**保存済みを開く** が編集セッションを閉じて保存バイトを開き、答えを
再検証してから入力を空にします。既にセッションが開いている場合は同じカードから
そのモデルを直接教えられます。実行に影響しなくなったスターターとデバイスの
選択欄は隠れます。

**まとめて教える** は累積の複数事実チェーンを開始します。**プログラムを作成** は
現在の事実を編集可能な `.machaon` プログラムにします。どちらも成功した編集の後で
利用できます。

### モデル

**モデル** には header 検査、tensor の名前・形状・型、任意のスターター
ダウンロード、セッションの dtype・デバイス・予算設定、ベースライン取得、重みを変更しない
単一事実の検証があります。ダウンロードは SSE で endpoint、ファイル、バイト進捗を表示し、
**ダウンロード後に開く** で完了後にセッションを開きます。

**事実を検証** は選択中のチェックポイントを再読み込みし、1 つの prompt/answer
または 1 行 1 事実を評価して PASS/FAIL、答え、精度を表示します。`/api/check` を
呼び、セッションは編集しません。

### 編集

**編集** は正確な契約エディターです。prompt、target、保護プロンプト、提案、
適用、評価、ロールバックを扱います。提案は dry run で、**適用** は
トランザクション内で書き込み、累積予算を消費します。ゲート失敗やロールバックでは
元のバイトに戻ります。

**詳細編集** で layer、solver、steps、学習率、module suffix、相対予算、densify を
設定できます。**まとめて教える** は事実ごとに検索を実行し、累積予算と元 panel の
ドリフトを確認します。**一括編集** は複数 prompt と活性化行を受け取り、
exact/clamped、誤差、rank、key ごとの誤差を表示します。

### 重みプログラム

**重みプログラム** は `machaon program` と同じ `.machaon` テキストまたは JSON を
受け付けます。**確認** は `/api/program/plan` を呼び、モデルを読み込まずにパス、
事実、予算、デバイス、出力を解決します。**実行** はバックグラウンドジョブとして
チェーンを実行し、`<output>/program-report.json` を書き出し、保存済み
チェックポイントを再読み込みして全事実を検証してから受理します。

**詳細** にはプログラムフォルダーとレポートパス、現在のチェックポイントからの
プリフィル、ローカル `.machaon` の読み込み、SmolLM2 / 2 事実 / バイリンガル Qwen
テンプレート、最近のプログラムと実行、事実リスト生成、レポート検証があります。
**レポートを検証** は SHA-256 と構造を確認し、**レポート + モデルを検証** は
チェックポイントも再読み込みして事実を再実行します。任意のチェックボックスで
現在のプログラムとの一致、または記録パスの代わりに選択中チェックポイントを使う
ことを要求できます。相対パスとブラウザーのファイルアクセスはすべて同じ許可
リストに従います。

### 結果

**結果** には最新の提案、fail-closed のゲート判定、チェックポイント保存、WSP
コントロール、トランザクション活動ログがあります。WSP はレポート監査、セッション
評価、証拠保存、OpenWSP 書き出し、バインディング検証に対応します。ゲート指標の
欠損は従来どおり失敗です。

### ローカル状態と言語

コンソールは English、简体中文、日本語、한국어 を提供します。上部の選択は静的
コピーと動的ジョブ/証拠メッセージを更新し、`localStorage` に保存されます。
`?lang=zh`、`?lang=ja`、`?lang=ko` の直リンクも使えます。最近のプログラムと
実行はローカル履歴だけで、アップロードされません。

## 大規模チェックポイント例：Qwen3.6-27B

コンソールはモデル非依存で、同じコントロールがすべての対応ファミリーに
使えます。27B は大規模チェックポイントの一例です。34 GB の統合メモリ環境では
`int4` または `int8` を使い、言語デコーダーの後半を編集点にします。

```text
path:      ./qwen36-27b
dtype:     auto
quantize:  int4
device:    cpu
layer:     60
budget β:  0.01
module:    mlp.down_proj
solver:    gradient
densify:   on
```

最初に header だけで checkpoint を確認してください。Transformers runtime、
単一 shard 書き込み、`Checkpoint.write_tensor` の詳細は
[Qwen3.6-27B ガイド](../guides/qwen27b.md) にあります。

## 運用ルール

コンソールは loopback に置き、許可ルートを実際に編集する checkpoint の
ディレクトリだけに絞ります。表示された token は session と checkpoint 書き込み
を承認する一時的な能力です。Web 層は任意の Python コードを受け取らず、パス
許可リスト、予算検査、トランザクション rollback を通します。
