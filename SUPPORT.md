# Support

## Questions and ideas

Use [GitHub Discussions](https://github.com/S0ra-ai/Machaon/discussions) for
design questions, reproduction reports and "how do I edit this?" threads. The
[FAQ](docs/faq.md) and [benchmarks](docs/reference/benchmarks.md) answer the
most common ones.

## Bugs

Open an [issue](https://github.com/S0ra-ai/Machaon/issues/new/choose) with:

- the model name and revision, if a checkpoint is involved;
- the smallest command or snippet that reproduces the problem;
- the output of `python -m machaon doctor` and `python --version`;
- whether the core install or the `hf`/`mcp` extra is in use.

## Security

Report vulnerabilities privately, as described in [SECURITY.md](SECURITY.md).
